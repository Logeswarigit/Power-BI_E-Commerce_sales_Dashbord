# Power-BI E-Commerce Sales Dashboard (Power BI)

## About This Project
I built an interactive Power BI dashboard to analyze e-commerce sales data and track key business metrics.

## Tools Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Visualization

## What I Did
- Connected and loaded the e-commerce sales dataset in Power BI
- Cleaned and transformed the data using Power Query
- Built KPI cards, bar charts, line charts, and donut charts
- Added slicers to filter data by category, payment method, and order status
- Created custom DAX measures for calculated metrics

## What I Found
- Tracked total revenue and monthly sales trends
- Identified top-performing product categories
- Analyzed payment method distribution across orders
- Monitored order status breakdown for business insights

## Dashboard Features
- Interactive slicers for filtering
- KPI cards for key metrics at a glance
- Category-wise and time-based analysis
- Clean, easy-to-read layout for business stakeholders
